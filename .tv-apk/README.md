# Call of Doom - Builder Test — Fire TV packaging

Generated by Game APK Builder. The source game is ./index.html. GitHub Actions packages the static game files, injects a native standard Gamepad API bridge, builds with the permanent repository signing key, verifies its certificate, and publishes game.apk to the game-apk-latest release.

Push changes to main to rebuild. Keep .game-apk-builder.json and .tv-apk/signing-certificate.sha256. Never replace the signing secrets to repair a build error; doing so changes the application's identity.

Automatic updates download APKs and verify SHA-256, package identity, version, and signing certificate. Fire OS still requires approval to install.

This does not convert server applications, build TypeScript/framework source, or add gameplay controls to games without Gamepad API support. Set gameFolder to a committed built site such as dist. Games requiring custom HTTP headers or browser features unavailable in Fire TV WebView need additional adaptation.
