Call of Doom
Fire TV app

A standalone fullscreen game with native Xbox controller input. For Fire OS 7 or newer.

Download Fire TV APK

  1. Open this page in Downloader by AFTVnews on your Fire TV.
  2. Select Download Fire TV APK, then Install.
  3. If installation is blocked, allow Downloader under Settings → Device & Software (or My Fire TV) → Developer Options → Install unknown apps.
  4. Launch Call of Doom from Your Apps & Channels. Move its icon to the front/home favorites.

If Developer Options is hidden, open About, highlight your device name, and press Select seven times, then go back. This is a test build: TV performance and controller behavior still need hardware testing. Internet is required for game libraries and fonts.
